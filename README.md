# EtTT2_Tef_Analysis
Repo containing analysis from a project investigating the protein structure and sequence similarity of Transparent Testa 2 homologues in a variety of plants.

PDB Files contain AlphaFold3 predictive folds using CDS sequences taken from Ensembl

Rasmol Scripts contain .pdb files of superpositioned copies of predictive folds of Arabidopsis TT2 against EtTT2a and EtTT2b generated using TM Align to view discrepancies between predictive folds of Arabidopsis TT2 and EtTT2a+b.

%ID_Matrix.xlsx was used to generate a heatmap figure in report, contains %ID match of CDS sequences from selected TT2 orthologues
AA_ID_Matrix.xlxs was used to generate a heatmap figure in report, contains %ID match of AA sequences from selected TT2 orthologues
TM_Align_matrix.csv was used to generate a heatmap figure in report, contains TM Score of aligned predictive folds from selected TT2 orthologues

HeatmapsFinal.Rmd is R Notebook containing code used to generate heatmap figures in report.
